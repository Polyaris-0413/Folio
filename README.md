<p align="center">
  <strong>拾页 Folio</strong><br>
  一款注重细节的本地阅读器
</p>

<p align="center">
  基于 Kotlin + Jetpack Compose 构建<br>
  适用于 Android 12 及以上的系统
</p>

## 特性
* 无广告、无追踪、无内购
* 使用 Material Design 3 设计
* 恰到好处的动画
* 书名识别 + 净化
* 目录识别
* 书本朗读（系统TTS）
* 自动导入读物
* AI 辅助
* 在线更新
